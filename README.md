# usj-eticket-log

USJの整理券系アトラクションが何時に発券終了したかの記録を公開している。

<https://niraura.github.io/usj-eticket-log/>

公式サイトの「本日のパーク情報」に出る整理券/抽選券の発券状況を5分おきに観測し、
その日の営業時間・天気とあわせて1行1日のヒートマップにしたもの。予測はしていない。

- 分かるのは「発券終了になったか」だけ。e整理券は入園後しか公式アプリに出ないため
  残り枚数は外から見えない
- 終了時刻は終了を最初に観測した時刻で、実際の終了はそれより前の可能性がある
- 観測できなかった時間はハッチングで区別している

`index.html` は別リポジトリの収集スクリプトが自動生成してpushしている。
